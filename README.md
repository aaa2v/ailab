# 춘천마이스(Chuncheon-MICE) AI 내비게이터

관심사·동행자·방문 일정을 말하면 그날 열리는 춘천 축제·행사와 주변 식당·카페·전통시장을 묶어 시간대별 관람 코스를 추천하는 웹 서비스입니다. 팀 폴라포가 **My AI 랩 프로젝트**로 개발합니다.

- 웹앱 데모: https://aaa2v.github.io/ailab/app/
- 상세 기획서: [docs/plan.md](docs/plan.md) (웹: https://aaa2v.github.io/ailab/plan.html)

## 지금 들어 있는 것 (MVP 시연판)

| 기능 | 내용 |
| --- | --- |
| 대화형 코스 추천 | 날짜·동행자·관심사·도착 시간·이동 수단을 대화에서 읽고, 빠진 조건은 선택 칩으로 물어봄 |
| 코스 조정 | "비 오면 실내로", "점심은 막국수로", "○○ 빼 줘" 등으로 다시 짜기, 이전 코스로 되돌리기 |
| 코스 검증 | 운영 시간·영업시간·이동 시간을 계산해 겹치는 코스는 보여 주지 않음 |
| 축제 목록·상세 | 기간·분야·실내 필터, 앞으로 7일 프로그램 시간표, 주변 1km 매장 |
| 지도·공유 | 춘천 개략 지도 위 번호 동선, 코스 텍스트 복사 |
| 피드백 | 좋아요/별로예요 (브라우저에만 저장) |

### 추천 엔진 두 가지

- **Claude 모드** — Claude 아티팩트로 열었을 때. Claude가 조건을 추출하고, 서비스가 넘긴 후보 목록(프로그램·매장 ID) 안에서만 코스를 짭니다. 결과는 코드가 다시 검증하고, 틀리면 오류를 알려 한 번 더 요청한 뒤 그래도 틀리면 규칙 기반 엔진으로 넘어갑니다.
- **규칙 기반 모드** — GitHub Pages 등 Claude를 쓸 수 없는 곳. 키워드로 조건을 읽고, 점수·이동 시간·식사 시간 규칙으로 코스를 만듭니다.

## 데이터 안내

장소 이름과 위치는 춘천의 실제 장소를 대략적으로 표시했지만, **행사 일정·프로그램·요금과 매장 이름은 모두 시연용 가상 데이터**입니다. 실제 서비스에서는 기획서 5장의 공공데이터(TourAPI, 전국문화축제표준데이터, 소상공인 상가정보 등)로 바꿉니다.

## 폴더 구조

```
docs/
  index.md               GitHub Pages 첫 화면
  plan.md                상세 서비스 기획서
  assets/architecture.svg 시스템 구성도
  app/index.html         웹앱 (HTML 한 파일, 빌드 불필요)
.github/workflows/pages.yml  GitHub Pages 자동 배포
```

## 로컬에서 실행

빌드가 필요 없습니다. `docs/app/index.html`을 브라우저로 열면 규칙 기반 모드로 동작합니다.

## GitHub Pages 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 `docs/`를 사이트로 배포합니다. 처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔야 합니다.
